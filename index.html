Bank Marketing: the column that fooled every modelব্যাংক মার্কেটিং: যে কলাম প্রতিটি মডেলকে বোকা বানাল

CSE445 group project, team of fourCSE445 গ্রুপ প্রজেক্ট, চারজনের দল

Predicting which bank customers subscribe to a term deposit (UCI Bank Marketing) with four families of models: classical ML, tabular foundation models (iLTM, TabPFN v2), fine-tuned transformers (DistilBERT, RoBERTa) and LLM prompting (Phi-3-mini). Written up as an IEEE-format paper.

UCI ব্যাংক মার্কেটিং ডেটাসেটে কোন গ্রাহক টার্ম ডিপোজিট নেবেন তার পূর্বাভাস — চার ধরনের মডেল দিয়ে: ক্লাসিক্যাল এমএল, ট্যাবুলার ফাউন্ডেশন মডেল (iLTM, TabPFN v2), ফাইন-টিউনড ট্রান্সফরমার (DistilBERT, RoBERTa) এবং এলএলএম প্রম্পটিং (Phi-3-mini)। আইইইই ফরম্যাটে গবেষণাপত্র আকারে লেখা।

  • Keeping the call-duration column raised ROC-AUC by about 0.14 in every pipeline — more than any difference between the models.
  • On a time-based split (train 2008–09, test 2010), ROC-AUC fell to 0.65.
  • TabPFN v2 reached almost the same F1 as iLTM (0.520 vs 0.527) with about 1/125 of the compute.
  • কলের সময়কাল (duration) কলাম রাখলে প্রতিটি পাইপলাইনে ROC-AUC প্রায় ০.১৪ বেড়ে যায় — যা মডেলগুলোর নিজেদের মধ্যে যেকোনো পার্থক্যের চেয়ে বেশি।
  • সময়ভিত্তিক স্প্লিটে (২০০৮–০৯-এ ট্রেন, ২০১০-এ টেস্ট) ROC-AUC নেমে আসে ০.৬৫-এ।
  • TabPFN v2 প্রায় একই F1 (০.৫২০ বনাম ০.৫২৭) পেয়েছে iLTM-এর মাত্র ১/১২৫ ভাগ কম্পিউটে।

My role: one of the two main contributors. I built the classical ML baselines, fine-tuned DistilBERT and RoBERTa, ran the iLTM, TabPFN v2 and Phi-3-mini experiments, and wrote the paper.

LeakGuard

Open-source Python libraryওপেন-সোর্স পাইথন লাইব্রেরি

A command-line tool and Python library that finds data leakage before it fools you: columns that predict the target suspiciously well, columns the whole model leans on, identifiers, duplicates, train/test overlap, and scores that collapse on a past-to-future split. Its exit codes let a CI pipeline stop on a serious leak.

একটি কমান্ড-লাইন টুল ও পাইথন লাইব্রেরি, যা ডেটা লিকেজ আগেভাগেই ধরে ফেলে: যে কলাম টার্গেটকে সন্দেহজনকভাবে ভালো পূর্বাভাস দেয়, যে কলামের ওপর পুরো মডেল নির্ভর করে, আইডেন্টিফায়ার, ডুপ্লিকেট, ট্রেন/টেস্ট ওভারল্যাপ এবং সময়ভিত্তিক স্প্লিটে ভেঙে পড়া স্কোর। গুরুতর লিকেজ পেলে এর এক্সিট কোড CI পাইপলাইন থামিয়ে দিতে পারে।

Built with Python, pandas and scikit-learn; tested on Python 3.10–3.13 with GitHub Actions.

ব্যবহৃত: Python, pandas ও scikit-learn; GitHub Actions-এ Python 3.10–3.13-এ পরীক্ষিত।
